3. Simulate natural user interaction through a simple interface or command-line system.
4. Collect feedback or inputs from users and adapt responses accordingly.

## Introduction

A prompt-based application uses carefully designed prompts to guide ChatGPT in generating useful and structured outputs. In this experiment, ChatGPT is used as a Daily Task Organizer that helps users manage schedules, prioritize work, and improve productivity.

The application evolves through different prompt engineering techniques:

Basic Prompt
Structured Prompt
Role-Based Prompt

Advanced Constraint Prompt

Ensure at least 7 hours sleep

## Comparison of Prompt Types
Basic Prompt: Low complexity, moderate output quality, low personalization.
Structured Prompt: Medium complexity, good output quality, medium personalization.
Role-Based Prompt: Medium complexity, better output quality, medium personalization.
Context-Aware Prompt: High complexity, very good output quality, high personalization.
Advanced Constraint Prompt: Very high complexity, excellent output quality, very high personalization.


## Conclusion

Prompt engineering significantly improves the performance of AI applications. By refining prompts with structure, context, and constraints, ChatGPT can generate highly useful and intelligent outputs for real-world applications such as task management, scheduling, budgeting, and planning.
